# Portfolio — Alan Bourlard

Site statique (HTML, CSS, JavaScript sans framework), prévu pour GitHub Pages.

- `index.html` : contenu en français
- `main.js` : traductions anglaises (bouton FR/EN) et thème clair/sombre
- `styles.css` : styles
- `assets/img` : images optimisées (WebP)
- `assets/retex` : retours d'expérience des projets de BUT (PDF)

Pour tester en local : `python -m http.server` puis ouvrir http://localhost:8000.
